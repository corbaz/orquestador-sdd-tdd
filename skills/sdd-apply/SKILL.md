# Skill: sdd-apply

## Proposito

Ejecutar las tareas del diseño respetando orden, dependencias y verificación.

## Cuando usar

Usar con `/pi:07-apply` después de `/pi:06-tasks`.

## Reglas

- Aplicar tarea por tarea, en el orden definido.
- Antes de cada tarea, revisar el requisito o escenario asociado.
- Aplicar TDD cuando corresponda (test primero, después implementación).
- Documentar cada tarea completada y su verificación.
- No saltar pasos de verificación.

## Proximo paso

Ejecutar `/pi:08-verify`.
