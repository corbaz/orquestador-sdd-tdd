# Skill: sdd-review

## Proposito

Generar el cierre versionable del ciclo.

## Cuando usar

Usar con `/pi:09-review` después de `/pi:08-verify`.

## Reglas

- Resumir tareas aplicadas y verificación de requisitos.
- Incluir evidencia de tests.
- Agregar recomendaciones finales y pendientes.
- No introducir cambios nuevos.

## Proximo paso
